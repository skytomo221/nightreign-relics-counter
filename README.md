# OCR自動補正ツール

## 概要

このプログラムは、特定のゲームのスクリーンショットからテキストを読み取り、整形してTSVファイルに出力するツールです。

主な機能は以下の通りです。

* **画像の一括処理**: `./data` フォルダ内にある画像ファイル（jpg, png）を自動で全て処理します。
* **高精度OCR**: 画像内の特定領域を切り抜き、二値化・白黒反転等の前処理を行うことで、Tesseract OCRによる文字認識の精度を向上させます。
* **自動補正**: OCRの認識結果を、事前に定義されたリストと照合します。**編集距離（レーベンシュタイン距離）**を用いて、最も近い候補に自動で補正します。
* **TSV出力**: 補正後の最終的な結果を、`results.tsv`に追記形式で保存します。

## 使い方

### 1\. 準備

* **画像ファイルの配置**: プログラムと同じ階層に`data`という名前のフォルダを作成し、その中に処理したいスクリーンショット画像（jpg, png）を入れます。
* **遺物リストの配置**: プログラムと同じ階層に`relics.tsv`ファイルを配置します。

最終的なフォルダ構成の例：

```txt
/あなたの作業フォルダ/
├── nightreign-relics-counter.exe  ← このプログラムの実行ファイル
├── Tesseract-OCR/  ← Tesseract OCR
│   └── tesseract.exe
├── data/  ← 処理したい画像を入れる
│   ├── image1.png
│   └── image2.jpeg
└── relics.tsv  ← 遺物リストファイル
```

### 2\. 実行

準備ができたら、`nightreign-relics-counter.exe` を実行してください。
黒い画面（コンソール）が立ち上がり、処理が開始されます。

### 3\. 結果の確認

処理が完了すると、プログラムと同じ階層に`results.tsv`というファイルが生成（または追記）されます。このファイルをExcelやテキストエディタで開くと、OCR結果を確認できます。

また、`temp`フォルダが自動で作成され、OCRの際に実際に読み込まれた二値化画像が保存されるため、デバッグに役立ちます。

## 開発者向けのセットアップ

ソースコードからプログラムを動かす、または改修する場合の方法です。

### 1\. 前提条件

* **Go**: バージョン1.20以上がインストールされていること。
* **Tesseract OCR**: プロジェクトフォルダ内の`./Tesseract-OCR/`に配置されていること。

### 2\. 環境構築

1. **リポジトリのクローン**:

    ```sh
    git clone [リポジトリURL]
    cd [リポジトリ名]
    ```

2. **ファイル配置**: 「ユーザー向けの使い方」で説明した通り、`data`フォルダと`relics.tsv`ファイルを配置します。

### 3\. 実行

以下のコマンドでプログラムを実行します。

```sh
make build
```

### 4\. ビルド

以下のコマンドで、`ocr-tool.exe`という名前の実行ファイルを生成します。

```sh
make build
```
